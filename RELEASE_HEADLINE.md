## Why

- Built for a machine left running: a MiSTer or console sitting at the start menu now shows the game instead of a frozen menu screen.
- The autopilot uses the player's own controls, so every level it exits is confirmed player-completable.

## Attract mode

- Leave the start list untouched for about 25 seconds and the game demos itself: PROCEDURAL commits on its own and an autopilot walks level after level to the exit, endlessly.
- ATTRACT MODE is also a row on the start list (bottom group, with CONTROLS and ASSET VIEWER) for starting the demo on demand.
- The autopilot drives the normal controls: it walks out of the lobby, finds the exit, opens the hinged door or climbs the hole, and crawls ducts when the path goes through one.
- Any button ends the show. In a level it fades back to the start list, where the idle clock arms again; during the lobby walk-out it hands over the controls instead.
- Every power-on demos a different first level.
- Rest-mode supersampling stays off during the demo, so the picture never parks on a still frame.

## Movement

- Walking into a crawl space drops into the crawl automatically and proceeds at crawl pace, the same way bulkheads already dip the head. The A+B crouch is unchanged — it is just never required to get through.
