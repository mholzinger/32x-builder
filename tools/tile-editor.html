SMS TILE EDITOR

Palette (0 = transparent)

Click selects a paint color. Double-click a swatch, then pick from the SMS master palette (64 colors) to retint the slot. Right-drag in the editor paints 0 (transparent). Colors snap to SMS levels on save.

Tile

Tile bank (/128, ids 128+)

Metatile (cell = 4x4 tiles)

Select a slot (yellow), then click a bank tile to assign it. Or select slot then press S to stamp the current tile.

Walk sheet — paint across all 4 frames

Pen/pick work here directly (right-drag erases). A painted tile that other frames share is cloned first, so each frame owns its pixels. Load a rip tileset from srcref/sms/rips/ to start from the extracted commercial cycles.

Map preview — arrow keys walk (8x6-cell viewport, like the ROM)
